# 项目背景与需求

> 人类与 AI 协作者都应先读本文。硬件事实见 [hardware/HARDWARE_NOTES.md](hardware/HARDWARE_NOTES.md)，
> 技术决策及理由见 [DECISIONS.md](DECISIONS.md)。

## 背景

[Navio Chron](https://github.com/Cityforest2000/Navio-Chron) 是社区开源的视频剪辑小键盘
（类似 TourBox），硬件由 Cityforest2000 设计（PCB V1.0 双板 + ESP32-S3 SuperMini 模块，
[oshwhub 工程](https://oshwhub.com/cityforest/)）。原固件为单文件 Arduino 草稿、仅 USB、
面向剪映。本项目为该硬件编写**全新配套固件**，实现原作者未覆盖的蓝牙、多预设、可配置能力。

**不复用上游代码**（上游仓库无 LICENSE，见 DECISIONS.md D6），只参考其引脚定义与行为手感。

## 输入硬件概览（详见硬件笔记）

12 颗带 WS2812 的热插拔按键、3 个编码器（中央旋钮 / 大旋钮 / 滚轮）、
滚轮下压微动（SW21）、侧面微动（SW11）、3 颗状态灯、电池接口（÷2 分压检测）。

## 核心需求

1. **连接**：USB 有线与 BLE 蓝牙二选一，支持切换；同一时刻只启用一种。
2. **预设**：按目标软件区分（Premiere Pro、DaVinci Resolve、剪映、Final Cut、Procreate，
   后续可扩展），Win / macOS 快捷键差异分别建预设；美式键盘布局。
3. **用途**：视频剪辑为主；绘图辅助为辅（滚轮做缩放、画笔选择等）。
4. **供电**：USB 常用；预留电池（模块内置充电，无充电状态引出）——
   需要睡眠唤醒、低电量指示、电池模式下控制 RGB 功耗。
5. **发布**：拟公开发布开源（许可证待定，发布前解决上游引用关系）。

## 明确的约束 / 非目标

- 不做 USB + BLE 同时连接。
- 没有屏幕；状态只通过 3 颗状态灯表达。
- 侧键固定为预设切换（不自定义）；其他 15 路输入全部可映射。
- **侧键手势**（分级长按，与单击零冲突）：**短按松手=切换预设**；
  **按住 5–10 秒后松手=蓝牙配对模式**（清绑定+可发现广播，不切换预设）；
  **长按 10 秒=固件烧写模式**（不清绑定、不切换预设）；插电/复位时按住=烧写模式。
  按住期间 LED1 实时渐变反馈进度（蓝渐亮→蓝转紫）。
  模块 BOOT 键长按 3 秒=烧写（裸板调试用，组装后难按仅兜底）。

## 状态灯设计（3 颗独立 RGB）

| 灯 | 职责 | 状态定义 |
|---|---|---|
| LED0 | 当前预设 | 预设 accent 色，单击侧键即变 |
| LED1 | 连接/模式 | 绿常亮=USB；蓝常亮=BLE 已连接；蓝快闪=配对中；橙慢闪=无线模式等待连接 |
| LED2 | 电源 | **未实现**：目标为绿(>60%)、黄(20-60%)、红慢闪(<20%)、红快闪(<10%)；当前仅低电红慢闪 |

侧键长按进度复用 LED1（0-5s 蓝色渐亮，5-10s 蓝→紫），松手或触发后恢复连接状态色。
- SW1 硬件开关只做电池通断，不承担模式切换语义（见 D3）。
